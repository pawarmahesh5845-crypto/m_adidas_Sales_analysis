# m_adidas_Sales_analysis

Project Title

Adidas Sales Analysis Dashboard using Power BI

Project Description

This project presents an interactive Adidas Sales Analysis Dashboard developed in Power BI to analyze sales performance across different regions, products, retailers, and time periods. The dashboard provides key business insights through dynamic visualizations and KPIs, helping stakeholders make data-driven decisions.

The analysis focuses on:

Total Sales Performance
Operating Profit & Margin
Units Sold
Product-wise Sales
Retailer-wise Sales
Region-wise Sales
Monthly Sales Trends
State-wise Sales Distribution
Tools & Technologies Used
Power BI Desktop
Power Query (Data Cleaning & Transformation)
DAX (Data Analysis Expressions)
Data Modeling
Interactive Visualizations
Project Workflow
1. Data Cleaning & Transformation
Removed duplicate records.
Handled missing/null values.
Corrected data types.
Standardized column names and formats.
Prepared clean and reliable data using Power Query.
2. Data Modeling
Created relationships between tables.
Designed an efficient star schema model.
Optimized data structure for better performance and reporting.
3. DAX Measures Created

Some important DAX measures used:

Total Sales
Total Profit
Total Units Sold
Average Price per Unit
Operating Margin %
Monthly Sales Calculations
Dynamic KPI Metrics
4. Dashboard Visualization

Created interactive visuals including:

KPI Cards
Monthly Sales Trend Chart
State-wise Sales Map
Region-wise Donut Chart
Product-wise Sales Analysis
Retailer-wise Sales Comparison
Region and Year Slicers
Key Insights
Sales Performance
Total Sales reached $105M.
Operating Profit generated $39M.
Overall Operating Margin stood at 42%.
Monthly Trend Analysis
Highest sales recorded in September ($18.3M).
Strong sales performance observed during August and September.
Lowest sales recorded in December ($3.4M).
Regional Analysis
Northeast Region contributed the highest share of total sales (38.74%).
Midwest region contributed the lowest share.
Product Analysis
Men's Street Footwear was the top-performing product category with $22M sales.
Women's Apparel closely followed with $21M sales.
Retailer Analysis
Foot Locker was the highest revenue-generating retailer with $41M sales.
Walmart secured the second position with $33M sales.
Dashboard Features

✔ Interactive Filters (Region & Year)
✔ Dynamic KPI Tracking
✔ Geographic Sales Analysis
✔ Product & Retailer Performance Comparison
✔ Trend Analysis for Better Decision Making

Conclusion

The Adidas Sales Analysis Dashboard provides a comprehensive overview of sales performance and profitability. Through effective data cleaning, data modeling, DAX calculations, and interactive visualizations, the dashboard helps identify top-performing products, retailers, and regions. The insights generated can support strategic business decisions, improve sales planning, and enhance overall business performance.
